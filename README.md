# Facial Emotion Recognition using Machine Learning

A Machine Learning project for detecting and classifying human facial emotions using deep learning and computer vision techniques.

---

# Overview

This project focuses on building a Facial Emotion Recognition (FER) system capable of identifying human emotions from facial images. The notebook implements a complete machine learning workflow including data preprocessing, model training, evaluation, and prediction.

The system classifies facial expressions into multiple emotion categories such as:

* Happy
* Sad
* Angry
* Fear
* Surprise
* Neutral
* Disgust

The project demonstrates how deep learning and computer vision techniques can be applied to emotion recognition tasks for real-world AI applications.
